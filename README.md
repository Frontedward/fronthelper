# FrontHelper - для фронтенд-разработчиков

FrontHelper - это веб-приложение, которое помогает фронтенд-разработчикам находить ответы на вопросы, связанные с разработкой.

## Основные возможности

- Поиск ответов на вопросы по фронтенд-разработке
- Простой понятный интерфейс
- Доступ к официальной документации

## Технологии

- Next.js
- TypeScript
- Tailwind CSS

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone [url-репозитория]
```

2. Установите зависимости:
```bash
npm install
```

3. Создайте файл .env.local и добавьте необходимые переменные окружения:
```
OPENAI_API_KEY=ваш_ключ
MONGODB_URI=ваш_uri
```

4. Запустите приложение:
```bash
npm run dev
```
